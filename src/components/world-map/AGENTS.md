# AGENTS - src/components/world-map

## Folder purpose

The `/mapa` page: a zoomable night-lights world where countries with open opportunities glow amber, with a side panel of destinations and, once a country is chosen, its opportunities.

## Files

- `map-explorer.tsx`: page body. Search and filters, the map, the panel, and the chosen country in the URL (`?pais=ca`).
- `opportunity-map.tsx` + `opportunity-map.css`: the Leaflet map (client-only, loaded with `next/dynamic`). Layers are driven imperatively; React only passes data in.
- `map-data.ts`: pure data. Builds items from the verified set and the catalog, filters them, groups them by country, and places pins.
- `map-panel.tsx`, `country-silhouette.tsx`: the side panel and the small country shapes in it.
- `countries.json`: country outlines, generated by `scripts/build-map-countries.mjs` from `src/utils/countries.geo.json`.

## Rules for agents

- Keep the list in the panel as the keyboard path: every country on the map must also be a button there.
- Countries come from each record's own country text (`findCountries`); pins come from the server-resolved `localizacoes`. Never place anything by hand.
- The map uses plate carrée (`L.CRS.EPSG4326`) so the equirectangular tiles and the outlines line up. Don't switch to the default Web Mercator.
- Tiles live in `public/map-tiles/v1`, cut by `scripts/build-map-tiles.mjs`. A re-cut goes to a new version folder; tiles are cached by URL.
- Pins and dots are HTML markers (`L.divIcon`), not SVG circles: Leaflet scales the vector layer during a zoom, so SVG dots balloon and then snap back.
- Colors come from the theme tokens in the CSS; no hex values in the component.
