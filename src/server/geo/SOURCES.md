# Place data

`cities.json` is generated by `scripts/build-geo-index.mjs` from GeoNames `cities15000.txt` (every city with 15,000+ inhabitants), downloaded from https://download.geonames.org/export/dump/cities15000.zip on 2026-09-21. GeoNames data is licensed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/); the maps credit it on the home page footer and under the catalog results.

To refresh:

```bash
curl -O https://download.geonames.org/export/dump/cities15000.zip && unzip cities15000.zip
node scripts/build-geo-index.mjs cities15000.txt
```

Server-only: the file is ~1.7 MB and is read by `resolve-location.ts` in route handlers and server pages. Never import it from a client component.
